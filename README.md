# AfriTalent
Projet fil rouge — Plateforme de mise en relation entre freelances africains et
clients.
Auteur : SAID ANRAFA
promotion : L1 DS&BD — ISI
Nom du Projet

Description

Ce projet est une plateforme web moderne développée dans le cadre du module de développement web. Il permet aux utilisateurs de découvrir différents services, consulter des témoignages, rechercher des articles, contacter l’administrateur via un formulaire et profiter d’une interface responsive avec mode sombre.

Fonctionnalités

* Navigation responsive
* Mode sombre / mode clair
* Animation des sections au défilement
* Compteurs animés
* Recherche d’articles
* Filtrage par catégorie
* Formulaire de contact avec validation
* Bouton retour en haut
* Compatible mobile, tablette et ordinateur

Technologies utilisées

* HTML5
* CSS3
* JavaScript (ES6)
* Bootstrap 5
* Font Awesome
